# Contributing to CarFeeCalc

1. Create a focused change.
2. For state-specific fees, cite an authoritative government source and effective date.
3. Add or update tests for calculation logic and edge cases.
4. Run `npm run typecheck` before submitting a pull request.
5. Do not commit secrets, private customer data, or provider credentials.

Changes that alter a fee should explain the old rule, new rule, jurisdiction, source, and effective date.
