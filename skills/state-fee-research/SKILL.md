# State Fee Research

Research vehicle fees for CarFeeCalc using authoritative sources.

## Source priority

1. State DMV/BMV/DOT/revenue agency
2. County or municipal government
3. Official tax authority
4. Only then use reputable secondary sources for context

## Workflow

- Identify jurisdiction and transaction.
- Find the official fee schedule or calculator.
- Capture amount, formula, eligibility, exceptions, effective date, and source.
- Check whether local taxes vary by ZIP/county.
- Flag stale or conflicting information.
- Never convert an uncertain value into an official-looking number.
