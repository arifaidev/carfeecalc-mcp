# Vehicle Fee Calculator

Build and maintain vehicle-fee calculators for CarFeeCalc.com.

## Rules

1. Identify the state and transaction type before calculating.
2. Separate registration, title, plate, sales/use tax, local taxes, EV fees, and optional charges.
3. Use authoritative government sources for every state-specific numeric rule.
4. Keep tax and fee formulas isolated by state.
5. Show itemized results and a clear total.
6. Never invent missing fees.
7. Record source URLs and effective/verification dates when available.

## Output

Return assumptions, inputs, itemized fees, tax base, taxes, total, and source/provenance notes.
